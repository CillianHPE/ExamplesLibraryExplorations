Visualisation

What fills a widget body: one mark (the chart, number or bar) plus the furniture that makes it readable (value, unit, delta, axis, legend, caption). The Widget spec owns the frame; this page owns the inside.

Where it sits

One layer below the widget. The same visualisation reads identically in a W1 tile, a detail rail or an uncontained section.

Widget Widget
Container that reports. Header, scope, local controls, body slot, footer, states.
Widget type Widget catalogue
The job (stat, trend, status list…). Each type names the visualisation it uses.
Visualisation this page
Fills the body slot. Mark + furniture, with fixed relative positions.
Mark
The encoding: big number, sparkline, meter, proportion bar, segments, donut, ranked bars, columns.
Furniture
Text and keys that make the mark readable: value, unit, delta, axis row, legend, caption.

Boundary. Widget title and scope say what is measured and over what. Furniture never repeats it.

One box

The number's 46px line box sets the height. Delta and unit form a 32px stack (two 16px lines, no gap) centred on it, 4px to the right. Missing pieces leave their line empty; nothing reflows.

Recommendation
Order delta on the top line, unit on the bottom line (S1).
Slots are fixed a missing unit or delta leaves its line empty (U1, N1). Never re-centre, never swap lines.
Inline is a separate row type for compact tiles (E), not a fallback for missing pieces.
Denominators go to the axis row or caption, never the delta slot.

M8Value only

What is the number right now?

Furniture
Value row and caption. Nothing else.
Rule
This is the fallback every other mark degenerates to when its data collapses. It is not a lesser mark; a widget that only needs a number should use it on purpose.
Degenerate
None. If the value itself is unavailable, the widget's no-data state takes over.
Rules carried from elsewhere
  • Colour text is always ink. Semantic colour lives in fills, dots, pills and marks. Single series --c-blue; status --red / --amber / --ok / --unknown.
  • Zero counts never listed in a legend.
  • Status order critical → warning → ok → unknown.
  • One mark per visualisation, one visualisation per widget body.
  • Copy fragments join with " · ". No spaced em dashes.
