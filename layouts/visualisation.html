Visualisation

A visualisation is what fills a widget's body: one mark (the chart, number, or bar) and the furniture around it (value, unit, delta, axis, legend, caption). This page names those parts, fixes where each one sits relative to the mark, and lists the workhorse marks with their allowed configurations. The Widget spec owns the frame; this page owns what goes inside it.

Where it sits

One layer below the widget. A widget type chooses a visualisation; the visualisation is the reusable unit, so the same stat-with-sparkline reads identically in a W1 tile, a T4 detail rail, or an uncontained page section.

Mark
The encoding: big number, sparkline, meter, proportion bar, segments, donut, ranked bars, columns.
Furniture
Text and keys that make the mark readable: value, unit, delta, axis row, legend, caption.

Boundary with the widget. The widget's title and scope line say what is measured and over what population and period. Furniture never repeats that: an axis row gives endpoints, not the period name; a caption interprets, it does not restate the title. The legend zone the widget spec reserves is populated by, and follows the rules of, this page.

Anatomy

Five slots, top to bottom, drawn inside a widget body. Only the mark is mandatory. Every other slot is optional but has one fixed position, so two visualisations side by side always line up. Slot gap is 6px between value row and mark, 6px between mark and axis row, 12px above legend and caption.

Mandatory Optional slot, fixed position when present

1 · Value row holds the headline number, its unit, and the delta on one baseline. It sits above the mark so the eye reads answer first, evidence second. Omit it when the mark carries its own values (ranked bars, status list).
2 · Mark is exactly one encoding. Text never appears inside the plot area of a chart; annotations live in the axis row or caption. The donut centre total is the one exception.
3 · Axis row is the minimal axis: two endpoints as "label · value". Used by time marks (sparkline, columns) and meters (0 · capacity). Never a full tick axis inside a widget.
4 · Legend appears only when the mark has two or more series or categories that colour alone cannot name. Single solid series never get one. Legend entries may carry values ("Critical 2").
5 · Caption is one sentence of interpretation or the single most important exception, in ink. It is the only slot allowed to contain prose.
Unit is not a slot: it attaches to the value (same baseline, smaller, softer) or to the axis-row values, never floating on its own.

Value row configurations

The value row is designed as one box: the number sets the height, and the delta and unit are sized and placed to fill exactly that height. Delta on the cap line, unit on the baseline. Whatever is missing leaves its slot empty rather than reflowing, so a strip of stats keeps every number, delta and unit on shared lines.

98warning issues%
Number text/3xlarge/medium: 36px / 500, line-height 46px, tabular numerals, color/text/strong. The glyph (cap line to baseline) defines the box height.
Delta 18px tall pill (or 18px line of plain text), top edge on the number's cap line. 10px gap to the number.
Unit 15px / 500, --gl-ink-soft, baseline aligned to the number's baseline.
Box is height-locked to the number. The side column grows only in width. Nothing wraps; long delta text is shortened, not stacked.

Delta presentation · candidates

How the delta itself is drawn is not yet locked. These are the candidates, each shown rising and falling. The choice is independent of the presence configurations above; whichever wins slots into the same 18px delta position.

1 · Ink + trend icon
7%7%
Quietest. Direction only, no judgement. Fits B and D where nothing is good or bad. Candidate for the default when judgement is not needed.
2 · Coloured text
7%7%
Ruled out. Colour in typography breaks the ink rule and fails contrast at 12px. Shown for completeness.
3 · Tinted pill + trend icon
7%7%
Current spec. Tint carries the judgement, text stays ink, the icon carries direction so tint and direction can disagree (up can be red).
4 · Tinted pill + simple arrow
↑ 7%↓ 7%
Same semantics as 3 with a lighter glyph. Reads faster at 12px, loses the "trend" feel. Either 3 or 4 becomes the default, not both.
5 · Amber pill · attention
warning issues14 unprotected
Not a direction. Used when the delta slot carries an exception count or a state that needs attention rather than a comparison.

Two decisions remain: pill or plain as the default when a judgement exists, and trend icon or simple arrow for direction. The ink rule and the 18px slot are fixed regardless.

Rules carried from elsewhere

Colour. Text is always ink. Semantic colour lives in fills, dots, pills and marks only. Single-series marks use --c-blue; multi-series use the viz palette in order; status uses --red / --amber / --ok / --unknown.
Zero counts are never listed in a legend; the mark shows absence.
Status order is critical → warning → ok → unknown in legends, segments and slices.
One mark per visualisation, one visualisation per widget body. A second chart is a second widget.
Copy. Axis-row and legend fragments join with " · ". No spaced em dashes anywhere.
