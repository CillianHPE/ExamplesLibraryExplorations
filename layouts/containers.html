Signal

A light grey background (var(--contained), #F7F7F7) is the only signal that a group of content is a contained module. Everything else — page headings, KPI strips, full-width tables — sits directly on the white page body, uncontained.

A module is contained when it's a self-sufficient unit someone would recognise on its own — a chart, a short list, a summary tile. A module stays uncontained when it already reads as part of the page: a heading and its KPIs, or a table that already fills the width of its section.
Header row

The header always carries the container's heading on the leading side. The trailing side is an optional slot for a single action — a link-out arrow, a menu, or a short chip. Never more than one trailing element.

Content header

The header row itself — leading heading (flex) + optional 36px trailing action — is its own component, used both as a container's header and as the title for an uncontained content section. Full breakdown, placements, and rules: Content header.

Nesting

A container is a single level of containment. Inside its body, group related items with dividers or spacing — never with a second grey background. Grey-on-grey reads as a bug, not a hierarchy.
