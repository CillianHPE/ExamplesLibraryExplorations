Scale
Full 24px scale is the default, standalone size — the same size as the heading in the Figma component. Inside a container, use the established compact variant instead (.card-head, 19px heading) rather than the full-scale class.
Trailing options

The trailing slot holds exactly one action. Pick the one that matches what the heading links to.

Rules
✓One trailing element maximum — an arrow, a chip, or an icon button, never combined.
✓Use the full 24px scale (.content-header) for an uncontained section title; use the compact 19px scale (.card-head) inside a container.
✓The heading always takes the leading side and consumes remaining width — don't shrink it to fit a trailing element.
✕Don't stack a content header directly above a card-head for the same title — pick the placement, not both.
✕Don't wrap a section header's trailing slot in a second background — it reads on the page body, unboxed.
Markup
