S3 · Recommendation cards

One card per item, each with its own controls. Cards are heavier than rows, so use them only when each item is a small task with a start and an end, and when there are three or fewer. The card gives room for a consequence or benefit sentence and a second, quieter action ("Mark as done", "Not now") that rows do not have.

S3a · Action cards

Do this week 3

Generated today · 15 workspaces
View all
Critical
Renew Compute Ops Management on Alpha Bank
Expires in 6 days. 240 devices lose management.
Renew
Critical
Enforce MFA in all 15 workspaces
No workspace enforces MFA, SSO or an IP allow list.
Set policy
Warning
Check 42 silent devices
Not reported for 7 days, mostly in Edge-North-Fleet.
View devices

Job: "Do these things." A short, ranked set of tasks that must happen, each with its consequence spelled out and one button to start.

Use when
Three or fewer must-do items with a clear owner, on a page the owner visits. Each card is a task, not a fact.
Not when
More than three; it becomes a carousel. Or when the items are findings to read rather than tasks to finish, which is S2a.
  1. Content header: heading "Do this week" + count pill, subtitle "Generated today · population"
  2. Trailing action: "View all" when more than three
  3. Card: severity pill · imperative title · consequence sentence · primary link · "Mark as done" (warning only) · X (warning only)
  • Sort: critical first, then warning
  • Title starts with the verb: "Renew…", "Enforce…", "Check…"
  • Body states the consequence with a figure: "Expires in 6 days. 240 devices lose management."
  • Exactly one link per card; no buttons
  • Never more than three cards; the fourth onward is behind "View all (n)"
  • Default: 2 or 3 cards
  • One card: one-third width, left-aligned (do not stretch)
  • Empty: section removed
  • Done: card leaves and the count drops; no completed state is shown here
  • Critical cards: no X, no "Mark as done"; they leave when fixed
  • Warning cards: X dismisses, "Mark as done" removes and records
  • Dismissed recoverable from "Show dismissed (n)" if any exist
  • Card 16 20 padding, r12, --contained
  • Variants: severity (critical / warning) × dismissible (no / yes)
  • Component props: count, cards (1–3) with severity, title, consequence, link

S3b · Opportunity cards

Suggested for this account 3

Based on how similar accounts are set up
Cost5 min
Consolidate 9 evaluation workspaces onto one plan
Similar accounts save about 12% by renewing together.
Compare plans
Visibility2 min
Turn on weekly email digest
Get this summary on Monday without signing in.
Hygiene10 min
Group 42 silent devices into a watch list
Filter them out of the main inventory until they report.

Job: "Here is what you could improve, if you want." Optional suggestions with a stated benefit and effort, which the reader is free to decline.

Use when
There is a recommendation engine, nothing is urgent, and the reader has slack. Settings, billing and workspace overview pages.
Not when
Anything that must happen; optional framing lets it be ignored. Or when you cannot say the benefit in one line.
  1. Content header: heading "Suggested for this account" + count pill, subtitle "Based on how similar accounts are set up"
  2. Trailing action: "Show dismissed (n)"
  3. Card: category pill (Cost, Visibility, Hygiene) · effort pill ("5 min") · X · title · benefit sentence · primary link · "Not now"
  • Sort by expected benefit, highest first
  • Category pill is grey; this list has no severity
  • Effort pill is a time in minutes, rounded to 2, 5, 10, 30
  • Body states the benefit in one sentence, with a figure if there is one: "save about 12%"
  • Secondary action is "Not now" (snooze), never "Mark as done"; the system can tell when it is done
  • Default: 3 cards
  • Fewer than 3: cards keep one-third width
  • Empty: section removed, not "No suggestions"
  • All dismissed: section removed; "Show dismissed" lives in account settings
  • Every card: X (dismiss for good) and "Not now" (30 days)
  • Dismissed recoverable from the header link while any remain
  • Category and effort pills both --grey-bg; effort uses margin-left:auto
  • Variants: effort (2 / 5 / 10 / 30 min)
  • Component props: cards (1–3) with category, effort, title, benefit, link

S3c · Getting-started steps

Get started 1 of 3

Three steps to a managed account
✓
Add your first devices
1,240 devices added across 15 workspaces.
Add more
2
Assign a subscription
Pick a plan for each workspace so devices stay managed after the evaluation.
Assign
3
Set a security policy
Require MFA or SSO and restrict sign-in by IP.

Job: "Set up the next thing." A fixed sequence for a new account, with one step live at a time and the others shown so the reader knows how long the road is.

Use when
First weeks of an account, or after a big new capability ships. The user is unfamiliar and the order matters.
Not when
The account is established; replace with S2c if steps remain, or remove entirely. Never on a page that already has a primary button.
  1. Content header: heading "Get started" + "1 of 3" pill, subtitle one line naming the goal
  2. Trailing action: "Skip for now"
  3. Card: step number (ink circle; ✓ in --ok-bg when done) · illustration slot 56px · title · body · one action
  4. Current step: 2px outline in --gl-heading and the page's only primary button
  • Fixed order, left to right; exactly one current step
  • Done step: ticked, body states the evidence, quiet "Add more" style link
  • Future step: numbered, body says what it will do, quiet "Preview" link
  • The primary button is the only one on the page; the content header drops its own while this section is shown
  • Three steps; if the journey has more, group them
  • Default: one done, one current, one future
  • All done: section replaced by a single "Setup complete" line for one visit, then removed
  • Skipped: hidden; reachable from account settings
  • No per-card dismiss
  • "Skip for now" hides the section for 30 days; "Skip setup" in settings hides it for good
  • Step circle 22 r11; current card outline: 2px solid --gl-heading; outline-offset: -2px
  • Illustration slot 56 tall, r8 (placeholder hatch in the example)
  • Variants: step state (done / current / future)
  • Component props: done, total, goal, steps (3) with state, title, body, action
