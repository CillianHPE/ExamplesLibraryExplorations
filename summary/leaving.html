Collapse, dismiss, or neither

Three different behaviours, three different words. "Hide" is not one of them: it promises the thing can come back but does not say where it went or how. Each example below is live; click the controls.

Collapse

The section stays on the page. The body folds up; the content header stays so the reader still knows what was there and its scope.

Reversible in place: the same chevron expands it. Persists per user.

For: digests and anything that describes state. Nothing is lost by folding it.

Dismiss

One item leaves the list. The section stays. The item is not deleted: it goes to a known place.

Reversible elsewhere: "Show dismissed (n)" in the trailing slot brings it back, greyed. Undo for a few seconds after.

For: findings and recommendations the reader can judge for themselves. Never critical.

Neither

No control on the section. It changes or leaves only when the data does: the finding is fixed, the deadline passes, the step is done.

Not reversible because nothing happens: the trailing slot holds only navigation or a refresh.

For: critical findings, compliance, billing, anything with a cost to not seeing it.

  • The section disappears when it has nothing to show; it is never shown empty
  • No per-user state at all. Everyone on the account sees the same list
  1. Trailing slot: navigation link only ("View all subscriptions"), or nothing
  2. Last column is present but empty, so the action column lines up with the other list shapes
  3. Otherwise identical to the Container anatomy; no extra affordances
  • Use when not seeing the item has a cost: money, compliance, loss of management
  • Use when the list is driven by facts the user cannot judge away (a date, a lapsed contract)
  • If users ask to "get rid of" one of these, the answer is to fix or renew it, not to add a ✕
  • Pair with a stat or filter elsewhere on the page so the list is not the only route to the data
  • Container with Trailing = link or empty; Row with dismissible = false
  • No collapsed or dismissed variants needed; fewer states to maintain
