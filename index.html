Five canonical page types for the GreenLake dashboard system. Open an archetype to see its low-fidelity spec and high-fidelity build side by side, and toggle between them.

Overview

Answer "Is anything wrong? How are we trending? What next?" in under 5 seconds. Every module is a summary plus one link deeper.

Analytics / Report

Answer "how are we trending, and why?" One question per page, told top-down, no secondary rail.

Object detail
