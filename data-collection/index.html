Data collection page archetypes

Five canonical patterns for pages that display collections of data — tables, grids, streams, charts and maps — covering ~90% of scenarios in data-intensive platforms (researched via Mobbin: Cloudflare, Vercel, Sentry, Supabase, Twingate, LangChain, Modal, Better Stack, DoorDash…). Click an archetype, then use the Lo-fi / Hi-fi toggle on the page to switch between the abstract pattern and a GreenLake-styled example.

1 · Filterable inventory table

"Find and manage these 1,847 things." — The workhorse. Search + filter chips + column controls, sortable columns, bulk-select action bar, pagination. Compare attributes, act in bulk.

Lo-fi ⇄ Hi-fi hi-fi: GreenLake Servers (triage strip, collapsible activity, pagination)
Evidence: Twingate, LangChain, Vapi, Cloudflare

2 · Card grid catalog

"Browse and pick one." — Identity over attributes: icon, name, description on uniform tiles; category pills with counts as the primary filter. Grids are for choosing, tables for managing.

Lo-fi ⇄ Hi-fi hi-fi: GreenLake Service catalog
Evidence: Codecademy, Langdock, marketplace patterns

3 · Faceted event stream

"What happened, when?" — Time-ordered logs/audit/alerts. Volume histogram doubling as a zoom brush, facet sidebar with counts, query bar as canonical state, dense expandable rows, live tail.

Lo-fi ⇄ Hi-fi hi-fi: GreenLake Audit log
Evidence: Cloudflare, Vercel, Modal, Better Stack, Railway

4 · Analytics explorer

"What's the trend? Where's the anomaly?" — Chart-first. A scoped query (metric · agg · group-by · filters · time) drives everything; headline chart + breakdown stay in sync.

Lo-fi ⇄ Hi-fi hi-fi: GreenLake Sustainability insights (KPI cards as metric switcher)
Evidence: Sentry, Vercel, Supabase, WRITER, HPE GreenLake

5 · Map / spatial view

"Where is the problem?" — Map + synced list, one collection with shared filters and selection. Pins encode severity and magnitude; popover links to detail; the map is a lens, never the source of truth.

Lo-fi ⇄ Hi-fi hi-fi: GreenLake Sites map
Evidence: DoorDash, Felt, Turo, Cloudflare geo
