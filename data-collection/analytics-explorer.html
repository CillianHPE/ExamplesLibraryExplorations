Archetype 4 — Analytics explorer. Chart-first collection page for aggregate questions: trends, capacity, consumption (Sentry Traces, Vercel Observability, Supabase reports). Rules: a structured query bar (metric · aggregation · group-by · filters · time range) is the page's state — everything below re-renders from it; headline chart pairs the current value + delta with the trend; hover reveals exact values, drag zooms time; secondary charts answer the obvious follow-ups; a breakdown table under the charts shows the same data as rows with sparklines, linking each group to its detail page; Save query / Add to dashboard make explorations durable. The chart is for spotting the anomaly — the table is for acting on it.
